# Five Seconds to Explain the Glass

Entry for the make.fun bounty [Five Seconds to Explain the Glass](https://make.fun/bounty/u-po-pu-five-seconds-to-explain-the-glass-934d9949).

The program writes one sentence — the excuse a house cat gives in the
five seconds after sweeping a glass off the table — to `/output/entry.txt`.

> The glass sat empty for four hours, so I recycled it — an empty glass is just a vase that gave up, and I don't keep quitters.

## Run

```sh
python3 main.py
```

Deterministic, offline, standard library only. Two runs produce byte-identical output.
